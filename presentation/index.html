QC Defect Monitoring Mobile

Koleksi lengkap tampilan antarmuka (UI) mobile app berformat Vector SVG (Fully Editable di Figma) dan @3x Retina PNG untuk presentasi Capstone Project Sistem Mutu Manufaktur PT Galaxy Mandiri Perkasa.

Device Frame: 390 x 844 pt (iPhone 14/15 Pro) Format 1: Vector .SVG (Text & Nodes Editable) Format 2: Raster .PNG (@3x 1170 x 2532 px) Aesthetic: Industrial Dark Mode
Cara Memasukkan & Mengedit SVG di Figma 100% Vector & Editable

Setiap berkas SVG dibuat dengan struktur layer semantik (StatusBar, AppHeader, KpiGrid, SpcControlChart, FormContainer, CustomTabBar), font Plus Jakarta Sans, serta kurva vektor presisi:

1
Drag & Drop Langsung ke Figma

Unduh berkas .svg → buka Figma di browser atau desktop → tarik (drag & drop) berkas SVG langsung ke kanvas Figma. Ukurannya akan langsung pas 390 x 844 pt.

2
Ungroup Layer untuk Mengedit

Pilih frame SVG yang telah dimasukkan, lalu tekan Ctrl + Shift + G (Windows) atau Cmd + Shift + G (Mac) untuk membuka grup layer.

3
Edit Teks, Warna & Komponen

Klik ganda pada angka metrik, label teks, atau batas grafik kendali SPC (UCL/CL/LCL) untuk mengubah teks maupun mengganti warna fill/stroke sesuai kebutuhan presentasi.
